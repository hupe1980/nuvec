nuvec is an array and machine-learning framework for Apple Silicon, written in Rust, with the programming model of [MLX](https://github.com/ml-explore/mlx). New here? Start with [Getting started](@/docs/getting-started.md), then read [Arrays](@/docs/arrays.md) and [Transforms](@/docs/transforms.md). The full API reference is on [docs.rs](https://docs.rs/nuvec).
