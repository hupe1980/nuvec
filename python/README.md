# nuvec (Python)

This package name is reserved for future Python bindings to
[nuvec](https://github.com/hupe1980/nuvec), a pure-Rust array framework for Apple Silicon
in the spirit of [MLX](https://github.com/ml-explore/mlx).

This release contains no functionality. To use nuvec today, use the Rust crate:

```sh
cargo add nuvec
```
